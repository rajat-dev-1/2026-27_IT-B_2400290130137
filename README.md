# CodeHealth AI

An explainable, repository-aware codebase health assistant.

This repository is organized as a monorepo with two independent applications:

- [`frontend/`](./frontend/README.md) — React + Vite dashboard and repository analysis UI
- [`backend/`](./backend/README.md) — Express API and BullMQ worker, backed by Neon PostgreSQL and Redis

See each project's own README for setup instructions, environment variables, and available scripts.
